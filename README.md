# Fast Loop Legal Pages

This repository contains the public legal-information pages for the Fast Loop app.

## Files

- `index.html` — landing page with links to both legal documents.
- `privacy-policy.html` — Fast Loop Privacy Policy.
- `terms-of-use.html` — Fast Loop Terms of Use.

## Publish with GitHub Pages

1. Upload all four files to the root of the `reibell/fast-loop` repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch (usually `main`) and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish publishing.

The expected page paths are:

- `/` — legal pages landing page
- `/privacy-policy.html` — Privacy Policy
- `/terms-of-use.html` — Terms of Use

Use the actual GitHub Pages domain shown in repository Settings → Pages. Do not assume the final domain until GitHub displays it.

## Before publishing

Review the legal text against the exact app build. In particular, confirm whether the app includes analytics, crash reporting, advertising, third-party SDKs, cloud backup/sync, or any data transmission not described in the Privacy Policy. Update the policy and App Store privacy disclosures if needed.

The documents are general templates and are not legal advice.
